mslklogistic — CRM для грузоперевозок
=====================================

Как посмотреть
--------------
1. Нужен Python 3 (на macOS обычно уже есть). Если нет — скачайте с python.org/downloads.
2. macOS: дважды щёлкните start.command
   Windows: дважды щёлкните start.bat
   Или откройте терминал в этой папке и выполните: python3 server.py
3. Откройте в браузере http://127.0.0.1:3000

Вход для демо (демо-данные уже внутри)
--------------------------------------
Администратор:  admin@mslklogistic.local    / admin123
Руководитель:   head@mslklogistic.local     / head123
Менеджер:       manager@mslklogistic.local  / manager123
Водитель:       driver@mslklogistic.local   / driver123
Механик:        mechanic@mslklogistic.local / mechanic123

Интерфейс переключается на английский кнопкой RU / EN в правом верхнем углу.

Все данные хранятся только в папке data рядом с приложением.
Чтобы начать с чистого листа — удалите папку data, при следующем запуске
демо-данные создадутся заново.
