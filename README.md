# mslklogistic

CRM для грузовых перевозок: клиенты, заявки, рейсы, автопарк, ремонты, задачи,
документы, финансы и отчёты. Работает локально, без внешних зависимостей:
Python 3 (стандартная библиотека) + SQLite, интерфейс — SPA без сборки.

## Запуск

```bash
python3 server.py
```

Приложение откроется на [http://127.0.0.1:3000](http://127.0.0.1:3000).
База и загруженные файлы создаются в `data/` при первом старте и в git не попадают.

## Демо-доступ

После первого запуска доступен демонстрационный рабочий стол `demo`:

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | `admin@mslklogistic.local` | `admin123` |
| Руководитель | `head@mslklogistic.local` | `head123` |
| Менеджер | `manager@mslklogistic.local` | `manager123` |
| Водитель | `driver@mslklogistic.local` | `driver123` |
| Механик | `mechanic@mslklogistic.local` | `mechanic123` |

Новые пользователи могут зарегистрироваться сами — они получают собственный
изолированный рабочий стол и не видят демо-данные.

## Личный аккаунт

Отдельный полноценный аккаунт создаётся только при наличии переменных окружения
(в коде и репозитории никаких личных данных нет):

```bash
MSLK_OWNER_NAME="Имя" \
MSLK_OWNER_EMAIL="you@example.com" \
MSLK_OWNER_PASSWORD="надёжный-пароль" \
python3 server.py
```

Аккаунт получает роль администратора и чистый рабочий стол `owner`.

## Возможности

- Дашборд: выручка, маржа, активные рейсы, напоминания о ТО и дедлайнах.
- Клиенты и контакты, карточка клиента с историей перевозок и документами.
- Перевозки по этапам (заявка → расчёт → подтверждение → в пути → доставка) с
  оплатами, расходами, субподрядом, документами и печатью.
- Заявки на перевозку с расчётом себестоимости, наценки и преобразованием в рейс.
- Автопарк: пробег, ТО, страховка, техосмотр, история ремонтов.
- Заявки на ремонт от водителей с фото и обработкой механиком.
- Задачи с приоритетами, сроками и исполнителями.
- Роли: администратор, руководитель, менеджер, водитель, механик.
- Отчёты, журнал действий, импорт клиентов из CSV/Excel, резервная копия базы.
- Интерфейс на русском и английском (переключатель в шапке).

## Структура

```
server.py          HTTP-сервер и раздача статики
crm/               модель данных и API (SQLite, без зависимостей)
public/            лендинг и SPA (public/app)
data/              база, загрузки и резервные копии (не коммитится)
```

## Требования

Python 3.10 или новее. Внешние пакеты не нужны.
